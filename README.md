# 雨云云应用：不用买服务器，按小时计费部署网盘、数据库和网站，新手也能一次跑通

想搭个网盘、挂个 Alist、开台 MySQL 做测试，传统做法只有两条路：租一台云服务器自己装环境，或者买虚拟主机但什么都不能装。两条路的前置成本都不低，前者要配系统、装面板、设防火墙，后者被限制得死死的。

云应用想解决的就是这件事。它把"部署一个应用"从"管理一台机器"里拆出来，你只挑应用和配置，剩下的交给平台。

## 云应用到底是个什么东西

全称 Rain Cloud Apps，缩写 RCA，是雨云基于 Kubernetes 做的容器应用平台。官方的定位说法是"高可用、高灵活性、易用"，实用一点的翻译是：**不用买服务器、秒级部署、按小时扣费的 1Panel / 宝塔**。

它内置了三个板块——App、网站、数据库，另外带一个应用商店。首批上架的应用有数百款，官方也明确说是用了 1Panel 社区的应用模板并适配了第三方商店，所以你在 1Panel 里见过的应用，这里大概率也有。

社区教程里出现过的东西包括：Cloudreve（网盘）、Alist（多存储挂载）、MySQL、FRP 服务端（内网穿透）、AstrBot（机器人框架）、Minecraft 基岩版服务端、Silly Tavern 等等。想找具体某个应用，直接在应用商店搜索就行。

## 和"买一台服务器"比，真正的差别在哪

不是便宜或贵的问题，而是你要不要为一个操作系统负责。

| 对比项 | 云应用（RCA） | 传统云服务器 |
| --- | --- | --- |
| 开通到可用 | 安装后几秒到几分钟，状态刷新约 1 分钟延迟 | 开机后还要配环境、装面板 |
| 计费方式 | 按项目每小时配置 + 流量扣雨点 | 包月/包年为主，按配置定价 |
| 停机是否还收费 | 应用停止也继续计费，必须删除才停扣 | 关机一般仍算资源占用（看厂商规则） |
| 系统维护 | 不用管系统，镜像由平台拉取 | 系统更新、安全补丁自己来 |
| 扩容 | 改 CPU/内存配额，立即生效并补差价 | 通常需要停机变配 |
| 适合谁 | 只想把应用跑起来的人 | 需要 root、要装自定义环境、要精细调优的人 |

如果你需要改内核参数、装特定驱动、跑非容器化的老程序，那还是老老实实买服务器。云应用的边界很清楚：它管应用，不管机器。

## 从注册到跑通第一个应用，实际路径长这样

**第一步：注册账号。** 用手机号或邮箱注册，新用户可以拿到 15 天云应用免费试用，期间可用的总资源上限是 8 核 8G。👉 [注册雨云账号，先领 15 天云应用试用](https://www.rainyun.com/MzA2MTc2_)

**第二步：创建一个项目。** 在云应用里点"我的项目 → 创建"，填个项目名。磁盘默认 1GB，每个项目的这 1GB 是免费的，不够可以后面扩容（扩容要算雨点）。项目相当于一个工作空间，可以把不同用途的应用分开。

**第三步：进应用商店装应用。** 搜索应用名，点安装，然后配置这几项：

- 应用版本（一般选默认的最新稳定版）
- 安装到哪个地区（浙江宁波 / 中国香港 / 日本东京）
- CPU 和内存限制（可选范围是 0.2 / 0.5 / 1 / 2 / 4 / 8 / 12 / 16 核，内存 0.125G 到 32G）
- 使用共享 IP 还是独立 IPv4
- 外部端口（可以自己改，不改就用默认）

安装页面底部会实时显示"预计每月消耗"，配置动一下数字就变，这个比什么都直观。

**第四步：等状态变成"运行中"。** 应用通常几秒就装完，但页面状态刷新可能滞后一分钟左右，别急着重装。

**第五步：找账号密码。** 这个是最容易卡住新手的环节。Cloudreve、AstrBot 这类应用不会在页面上给你初始密码，要进"应用管理 → 日志"里翻。AstrBot 的日志里会打印 Initial username / Initial password，Cloudreve 同理。

**第六步：访问。** 应用管理里的"服务"页会列出地址和端口映射，点端口图标可以复制"IP:端口"。注意共享 IP 的情况下，外部端口和内部端口通常不是同一个，比如容器内是 19132，外面可能是随机分配的 47825，用错端口当然打不开。

**第七步（可选但推荐）：挂域名开 HTTPS。** 在项目的网站管理里新增一个"应用代理"类型的网站，域名可以用雨云自动分配的 `.rainapp.top` 二级域名，也可以绑自己的域名，然后在 DNS 那边加一条 CNAME 记录。宁波区域需要域名已备案，香港和东京不需要。

> 小结一下：真正会拦住人的只有两个点——日志里的初始密码，和共享 IP 下被映射过的外部端口。把这两件事记住，第一次部署基本十分钟内能完成。

## 费用怎么算：雨点这套机制

云应用不扣账户余额，只扣**雨点**，这是一个独立的计费单位。几个必须知道的规则：

- 雨点和人民币不是 1:1 绑定，充值越多单价越低。有教程记录过"充 100 雨点需要 90 元"这一档，小额充值时接近 1 元 1 雨点，具体比例以充值页面为准。
- 充值流程是两步：先往账户余额充值，再把余额兑换成雨点。
- **雨点充值后不支持退款**，第一次别换成吨。
- 新用户首次充值雨点有双倍活动。
- 每个项目免费赠送 1GB 磁盘。
- 内网传输流量不计费。
- 每小时自动扣款一次，应用停止运行也照扣，只有删除才会停。
- 最小计费单位 0.0001 雨点。
- 安装新应用或调整已有应用配置时，会立刻收取"到下一个计费小时"的差价，这叫变配补差价。举个例子：当前 14:30，下次结算是 15:00，把一个每小时 1 雨点的应用调到每小时 2 雨点，会马上扣掉半小时的 1 雨点。

## 几个实际场景，值不值一目了然

**个人网盘 / 图床**：Cloudreve 装完改个域名就能用，最低档月消耗 4 雨点左右。对个人备份量来说够用，但如果把文件公开分享给一堆人下载，宁波的流量单价（0.048 雨点/GB）会明显比香港舒服。

**远程数据库**：装个 MySQL，从本地 Navicat 连过去，测完就删。按小时计费在这里的优势最大——用两小时就只扣两小时，比开一台包月服务器测数据库合理得多。

**FRP 内网穿透**：香港集群 + 最低配 + 一个独立 IPv4，月成本大致在十几雨点的量级。相比买固定带宽的穿透套餐，你能拿到独享公网 IP 和任意端口，这是社区教程里被提得最多的用法。

**MC 开服**：教程里的建议是 2 核 4G 起步，10 人在线以上考虑 4 核 8G。基岩版默认端口 19132，用共享 IP 时这个端口基本被占用，得换个随机端口。开服这种场景要注意：**服务器空着不玩，雨点照样在扣**，寒暑假开、平时删，才是省钱玩法。

**建站**：PHP 站（WordPress、Typecho、Discuz 等）走"应用 + 网站代理"的路线，操作体验接近虚拟主机。宁波要备案，香港和东京不用，做纯海外站直接选香港。

## 容易踩的坑

- **以为停掉就不花钱**：应用停止后仍然每小时计费，嫌贵就删项目。
- **忘了流量也要钱**：资源费只是底价，流量按上小时用量每小时结算。
- **独立 IP 并非必需**：共享 IP 完全够个人用，先别多花那 30 雨点/月。
- **镜像拉取失败**：国内节点拉 Docker Hub 有时会失败，教程里常见的解法是换镜像加速地址后重建容器。
- **日志里的初始密码别外泄**：那行 Initial password 截图发论坛相当于把管理面板送人，登录后第一件事就是改密码。
- **磁盘扩容不能靠猜**：调硬盘容量本身也消耗雨点，用完再扩。

## 常见问题

**云应用等于 VPS 吗？**
不等。你拿到的是一个跑着容器的服务，没有 root、不能换内核。想自由折腾系统就买云服务器。

**必须备案域名吗？**
宁波区域需要，香港和东京不需要。用平台分配的 `.rainapp.top` 二级域名则不需要自己备案。

**新用户要花多少钱才能试？**
不用花钱。15 天免费试用期内总资源上限 8 核 8G，试用结束后才需要兑换雨点。

**雨点充多了能退吗？**
不能。建议先小额兑换，确认消耗速度再决定。

**能不能自己打包应用给别人用？**
可以。平台提供了应用模板功能，支持上传自己的模板，也能分享给其他人使用。
